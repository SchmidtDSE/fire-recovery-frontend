Fire Severity

How It Works

  1. Draw the fire perimeter on the map, or upload it as a zipped shapefile or GeoJSON.
  2. Name the fire, choose a satellite and set the pre-fire and post-fire date ranges.
  3. Submit. The analysis runs on our servers and takes a while.
  4. We email you when it finishes, with links to the burn severity maps (dNBR, RdNBR and RBR).

Only the perimeter's bounding box is used, and the perimeter is not stored. If the same analysis has already been run, the results are shown right away.
