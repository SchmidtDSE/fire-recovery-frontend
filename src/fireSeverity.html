Burn Severity Analysis

Outline a fire and choose dates. We compute dNBR, RdNBR and RBR from satellite imagery and email you when the maps are ready.

How it works
  1. Draw the fire perimeter on the map, or upload it as a file.
  2. Name the fire, choose a satellite and set the pre-fire and post-fire dates.
  3. Submit. The analysis runs on our servers and can take a while.
  4. When it finishes, the results appear here if the page is still open, and we email you links to them.

Only the perimeter's bounding box is used, and the perimeter is not stored. If the same analysis has been run before, the results appear right away.
